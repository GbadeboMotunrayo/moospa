## 🎨 DESIGN SYSTEM SPECIFICATIONS

### Color Psychology
- **Primary Pink (#e91e8c)**: Confidence, sensuality, luxury, empowerment
- **Dark Backgrounds (#0d0d0d, #1a1a1a)**: Sophistication, premium positioning
- **Gold Accents**: Luxury, opulence
- **Ivory/Cream**: Elegance, purity

### Typography Strategy
- **Headlines**: Serif (Georgia, Playfair Display) - elegant, timeless
- **Body**: Sans-serif (Segoe UI, Inter) - clean, readable
- **Accent**: Elegant script (optional) - for luxury touches

### Tone & Voice
- Sophisticated yet approachable
- Empowering and confident
- Sensual but never crude
- Luxurious and premium
- Inclusive and diverse

## 📧 DELIVERY CHECKLIST

**Format Requirements:**
- Images: JPG (72dpi web) & PNG (transparency) for web
- High-res versions: TIFF or PSD (300dpi) for print
- Videos: MP4 (H.264) optimized for web
- Documents: PDF & editable formats

**File Naming Convention:**
```
category_type_description_version
Example: skincare_product_glow-booster-cream_01.jpg
```
