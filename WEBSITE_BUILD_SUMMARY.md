## How to Use

### To View Website
1. Open App.jsx in your React application
2. Default view shows the customer website
3. Navigate between Home and Shop pages
4. Add products to cart
5. Use search and filters to discover products

### To Access Admin Panel
1. Click the "Admin" button (bottom right, pink)
2. Login with: admin@ndo.com / ndo2025
3. Manage products, categories, and settings

### To Return to Website
1. From admin panel, click "View Website" button
